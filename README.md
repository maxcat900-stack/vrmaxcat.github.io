# Густой лес — WebXR (одна страница)

Процедурный лес: сосны, берёзы, дубы, кусты, грибы (мухоморы, белые, лисички), трава,
камни и валежник. Ходьба в шлеме (стик) + телепорт (trigger), на десктопе — мышь и WASD.
Без зависимостей: чистый WebGL2 + WebXR Device API, одна сборка `a.html`.

## Запуск (PCVR, Edge)

```
vr.cmd
```

`vr.cmd` собирает `a.html`, поднимает локальный сервер на PowerShell (`http://localhost:8080`)
в свёрнутом окне и открывает Edge. WebXR работает только из безопасного контекста,
поэтому `file://` не подходит — нужен `http://localhost`.

Вручную:

```
build.cmd
serve.cmd            REM http://localhost:8080/a.html
```

Кнопка «Войти в VR» активна, если Edge видит VR-устройство. Если нет:
запусти рантайм шлема (Windows Mixed Reality portal / SteamVR), не используй приватное
окно, проверь `edge://flags/#webxr`. Без шлема работает режим обзора на экране.

## Управление

| Где | Действие |
|---|---|
| Десктоп | мышь (drag) — осмотр, `W A S D` / стрелки — идти, `Shift` — быстрее |
| Шлем | стик — ходьба, тачпад — плавный поворот |
| Шлем | навестись контроллером на землю и отпустить `trigger` — телепорт (куржок-кольцо) |

Граница леса — круг радиусом 33 м; дальше лес продолжается визуально, но упирается в невидимый забор.

## Структура

```
src/00-head.html     HUD, стили, открытие <script>
src/10-core.js       canvas, WebGL2-контекст, вывод ошибок
src/20-math.js       матрицы, шум, PRNG, локальные трансформации (scene -> reference space)
src/30-geo.js        генераторы геометрии (трубы, конусы, блоки листвы, трава)
src/40-forest.js     прототипы растений и раскладка леса (сетка занятости, коллизии)
src/50-shaders.js    GLSL: мир, земля, небо, тени-декали, курсор, луч, виньетка
src/60-gl.js         программы, VAO, буферы инстансов
src/70-render.js     отрисовка вида: небо -> земля -> инстансы -> декали -> курсор
src/80-move.js       игрок, коллизии, забор, телепорт, ходьба на десктопе
src/90-xr.js         XR-сессия, позы контроллеров, стик, прицел телепорта
src/95-boot.js       десктопный цикл, ресайз, параметры строки запроса
src/96-selftest.js   selftest перемещения и телепорта (?selftest=1)
src/99-tail.html     закрытие тега
a.html               сборка (артефакт, публикуется как есть)
```

Сборка — простая конкатенация (`build.cmd`, `copy /b`), Node и Python не нужны.
Порядок файлов задаётся списком в `build.cmd`.

## Параметры строки запроса

- `?seed=12345` — другой лес (по умолчанию `20261123`)
- `?x=3&z=8`, `?yaw=1.2&pitch=-0.2` — стартовая позиция и вид
- `?selftest=1` — прогнать проверку инвариантов; результат в строке `#perf`
  (например `SELFTEST OK rays=164/400 kinds=10 drawn=1602 tris=134k glErr=0 trees=1225 mush=2233`)

## Как это устроено (коротко)

- Каждый вид растения — один прототип-меш; весь лес рисуется инстансами
  (`drawArraysInstanced`), по одному вызову на вид. Кадровая фильтрация: по дальности
  и по конусу обзора, поэтому в кадре ~1,5 тыс. инстансов и ~130 тыс. треугольников.
- Точность не важна для ориентации граней: отсечение граней выключено, а нормаль во
  фрагментном шейдере разворачивается к наблюдателю — поэтому трава и листва двусторонние.
- Точка зрителя в сцене (`player`) и якорь XR (`hf0`) разделены: `local-floor` даёт
  физическое перемещение в комнате, `player` — виртуальное (ходьба/телепорт), поворот —
  вокруг якоря.
- Тени — инстансные радиальные декали на земле, плюс «пятнистый» свет на земле в
  шейдере (листва колышется, пятна тоже).
